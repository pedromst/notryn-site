GitHub Sync

Use the same Brain on all your computers

GitHub Sync keeps your Brain the same on several computers, through a private GitHub repository you own. Free during the beta. Later, sync may become an optional paid feature at a low price, with a one-time option. The app itself stays free.

Set up sync →
  1. Create a private repositoryOn GitHub. Empty, any name. Your notes live there, not on a Notryn server.
  2. Connect a fine-grained tokenAccess to that repository only, with Contents read and write. Notryn keeps it in your system keychain.
  3. Choose the same repository on each computerOn a new computer, create an empty Brain and pick the repository. Your notes arrive on the first sync.

Good to know.

How do I build a Brain?

Start small. Write one note for each idea, project or person, and link the notes that belong together so they join up in the Brain. Give your AI tools access to the folder, and they can read these notes and, if you allow it, help keep them up to date. For the idea behind it, read Andrej Karpathy's LLM Wiki, a short guide to building a personal wiki that AI tools can read and maintain.

Does it work with my existing notes?

Connect a folder of Markdown files. Notryn follows your folders and reads Markdown links and wiki links between notes. Your files stay in their original location.

Is there a mobile app?

Not yet. A mobile version is in development, with no release date yet. Because your Brains can sync through your own GitHub repository, the same notes will be ready for it. Today Notryn runs on Linux and macOS.

Is it free? What about sync?

The app itself stays free. To keep a Brain the same on several computers, connect it to a private GitHub repository you own. Your notes go only to GitHub, never to a Notryn server, and no Notryn account is needed. Free during the beta. Later, sync may become an optional paid feature at a low price, with a one-time option.

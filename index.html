  1. Create a private repositoryOn GitHub. Empty, any name. Your notes live there, not on a Notryn server.

Questions about Notryn

Is it free? What about sync?

The app itself stays free. To keep a Brain the same on several computers, connect it to a private GitHub repository you own. Your notes go only to GitHub, never to a Notryn server, and no Notryn account is needed. Free during the beta. Later, sync may become an optional paid feature at a low price, with a one-time option. How to set it up.

Where are my notes stored?

On your computer, as Markdown files in the folders you choose. Normal note taking does not send your notes to Notryn or to an AI provider. If you turn on GitHub Sync, they also go to your own private GitHub repository.

What if I stop using Notryn?

Your notes are ordinary Markdown files, so you can open them in other editors. If you uninstall, your notes, connected folders and settings are kept. If you use sync, your notes stay in your GitHub repository.

Does it work on macOS?

Yes, as a beta. The same install command works on Intel and Apple silicon Macs. The beta does not have Apple signing yet, so macOS may block the download. Do not turn off Gatekeeper. A signed Mac release will follow.

Which AI tools can read my notes?

Any AI tool that can read files on your computer. Open your AI in your Brain folder, or tell it where your Brain is. Nothing is sent to an AI automatically, and Notryn has no AI of its own.

Does it work with my existing notes?

Connect a folder of Markdown files. Notryn follows your folders and reads Markdown links and wiki links between notes. Your files stay in their original location.

How do I build a Brain?

Start small. Write one note for each idea, project or person, and link the notes that belong together so they join up in the Brain. Give your AI tools access to the folder, and they can read these notes and, if you allow it, help keep them up to date. For the idea behind it, read Andrej Karpathy's LLM Wiki, a short guide to building a personal wiki that AI tools can read and maintain.

Is there a mobile app?

Not yet. A mobile version is in development, with no release date yet. Because your Brains can sync through your own GitHub repository, the same notes will be ready for it. Today Notryn runs on Linux and macOS.

Can I contribute or use the source code?

Visit the Notryn GitHub project for the code, issues and development updates. Contributions are reviewed before merging. The software license and contributor terms define what is permitted.

# Neura landing page

This repository publishes the public landing page for [Neura](https://pedromst.github.io/neura-site/), a local-first Markdown workspace for writing, organizing and seeing how notes connect.

The application code remains in a private preparation repository while its security, packaging and public license are reviewed. This repository contains only the static landing page and does not include the Neura application or user data.

## Local preview

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000`.
